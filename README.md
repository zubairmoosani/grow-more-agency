# Grow More Digital Agency

Company site for Grow More — web, mobile, custom software, and POS.

Clean White theme. Next.js, TypeScript, Tailwind CSS.

```bash
cd ~/Desktop/grow-more-agency
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Contact form submissions append to `data/leads.jsonl` (not committed).

Update email, phone, and domain in `src/lib/site.ts` before going live.
